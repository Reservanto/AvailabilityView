# Milníky

Každý milník má vlastní složku `docs/milestones/<Mx>/` s plánem, průběhem a zprávou podle šablon v `docs/templates/`. Jak milník probíhá, popisuje `docs/ai-working-agreement.md`.

První verze vznikla před zveřejněním repozitáře a její milníky tu nejsou. Co z nich dál platí, je v `docs/SPEC.md` a `docs/decisions.md`. Číslování pokračuje šestým milníkem.
